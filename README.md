# 大相撲ブラザーズ ～ SUMO BROS.

スーパーファミコン風のドット絵で作った、力士が主人公のオリジナル横スクロールアクションゲームです。
外部ライブラリ・CDNを一切使わない単一HTMLファイルなので、`index.html` を置くだけで動きます。

## 遊び方
- 移動：← → キー（または A / D）
- ジャンプ：Space / ↑ / W
- 必殺技「ぶちかまし」：Shift / X（横の敵を吹き飛ばす無敵ダッシュ）
- ミュート：M
- 決定（スタート／リトライ）：Enter
- スマホは画面のタッチボタンで操作できます

`?` ブロックの真下からジャンプして頭で叩くと、塩（コイン）やちゃんこ鍋（パワーアップ）が出ます。
ちゃんこ鍋を取ると体が大きくなり、レンガを壊せて、敵の攻撃を一度だけ耐えられます。

## 公開について
ゲームのコード・ドット絵・効果音・BGMはすべてこの作品用に新規制作したオリジナルです。
特定企業のキャラクターやアセットは使用していません。
